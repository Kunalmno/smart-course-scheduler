# Smart Scholar Scheduling System

Academic scheduling dashboard for managing room allocation, timetables, and automated conflict detection and resolution.

## Design implementation

The interface follows a product-specific Unslop pass: restrained neutral surfaces, a consistent spacing rhythm, quiet borders, aligned iconography, readable labels, and motion limited to useful interaction feedback. Existing scheduling features and content remain intact.

## Development

```bash
bun install
bun run dev
```

Available scripts:

- `bun run build` — production build
- `bun run lint` — TypeScript check
- `bun run test` — test suite
